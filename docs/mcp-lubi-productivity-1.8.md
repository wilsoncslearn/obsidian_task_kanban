# Lubi 1.8.0 产品增强与验收说明

## 范围与入口

本轮在既有未提交工作区上增量实现六项功能和 AI 安全修复，不提交、不推送、不创建 Release。入口：面板更多菜单 → **工作复盘与整理**，或 Obsidian 命令面板中的五个独立命令。

1. **投入与成果**：任务／项目累计本人用时、待确认用时、独立总预算和余额；后台墙钟标注单列。包含归档任务的历史投入，不将多条记录中的预计快照相加。按记录累计投入，不是去重后的时间覆盖。
2. **周复盘行动**：按自然周保存 Markdown 周报，记录本周发现和下周行动，回看上一周承诺；可明确选择生成独立未安排任务。同一周相同原文使用稳定 ID，失败重试或重复保存不重复建任务。改写行动原文视为新行动，不同步覆盖旧任务。
3. **成果与验收关联**：支持 `[[笔记#区块]]` 与 HTTP(S) 成果链接、验收清单、带时间的交付／验收／返工记录。验收意见与任务完成状态独立，不自动生成用时；重复任务的具体发生日写在意见中。返工必须有原因，记录验收通过要求清单全部勾选。
4. **待整理**：批量改期、退回未安排、归档，支持本会话最近一次整理的冲突保护撤销。一次性任务可拆分为多个未安排行动并归档原任务。原记录保留；拆分不继承预计，不提供快捷撤销。归档任务可从投入与成果取消归档。重复任务仍在原计划页按发生日处理。
5. **实时计时**：关联任务后开始／暂停／继续，状态随设置保存，重启可续接。停止后先看分段预览并明确确认再保存。暂停空隙不计，跨午夜拆分，分段不足一分钟尾数舍去。稳定记录标记保护部分失败后的重试；任务不会自动完成。离开插件不会自动暂停，超过八小时提醒核对，不自动监测空闲。
6. **隔离数据恢复**：校验完整导出 v1／任务 v14，预览数量、疑似重复和失联引用；新建独立恢复目录，保留原始 JSON、任务文件和日记记录。绝不替换当前任务／日记／设置；失败保留明确标识的部分副本。不支持原位覆盖或自动合并。

## 数据与安全

- 保持任务 schema v14；新增可选预算、验收、归档和改期次数字段。计时状态保存在插件设置，不把后台耗时混入本人统计。
- 真实日记仍只由既有 Journal 的 `## 记录` 写入路径处理。测试全部使用合成数据／模拟 Vault，不使用个人记录作夹具。
- 隔离恢复不是完整 Vault 恢复：导出不包含日记其他章节、插件设置、附件或主题。原始 JSON 用于保留未知字段；在独立 Vault 中配置任务路径与分类后验证，不自动切换当前 Vault。
- API Key 改为会话内使用；保存设置时写入空 Key。检测到旧版明文 Key 时显示说明，下次保存设置清除当前设置文件中的 Key。历史备份／同步副本需用户自行清理，不能声称历史秘密已经抹除。
- curl 不再跳过 TLS 校验，禁用外部 curl 配置；凭据和请求正文经标准输入传递，不放在进程参数中。远程接口强制 HTTPS，HTTP 仅允许 localhost／回环地址。不自动联系真实 AI 服务。
- 异步操作有繁忙保护；批量任务修改与撤销比对已观察快照，拒绝覆盖并发改动。周报保存比对原文；已创建行动不会因周报写入失败而重复生成。

## 模块

- `插件源码/lubi/src/core/productivity.ts`：累计投入、计时拆分、导出校验、验收数据校验。
- `插件源码/lubi/src/core/productService.ts`：批量整理、计时保存、周报与隔离恢复。
- `插件源码/lubi/src/ui/productivity.ts`：五个功能页与确认交互。
- `插件源码/lubi/src/core/tasks.ts`：可选元数据及冲突保护批量写入。
- `插件源码/lubi/src/core/curl.ts`、`插件源码/lubi/src/main.ts`：TLS、地址校验、会话 Key、功能入口。
- `插件源码/lubi/test/smoke/productivity.mjs`：合成数据的功能／失败／并发／幂等／UI 交互测试。
- `插件源码/lubi/test/layout/productivity-layout.mjs`：生产 UI 的 Chromium 明暗主题、320／900px、五个功能页共 20 个布局场景。
