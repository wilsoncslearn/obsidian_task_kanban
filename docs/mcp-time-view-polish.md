# 日期导航与用时视图视觉打磨

## 范围

仅调整日期导航、我的用时列表和日历记录时间块的视觉样式，不改任务、日记、日期切换、记录编辑、拖动或统计逻辑。保留现有黑白灰设计体系和浅深主题变量，不引入分类色、网络字体或新依赖。

## 实现

- `插件源码/lubi/src/styles/14-display-fixes.css`：日期导航使用统一圆角和间距；箭头去掉独立外框，回到今天使用轻底色。
- `插件源码/lubi/src/styles/12-mono.css`：用时列表改为有间距的浅底圆角条目，清除继承的四边按钮描边；时长使用独立轻量标记，元信息字号和字重统一；新增记录按钮使用较轻边框。
- `插件源码/lubi/src/styles/02-topbar-daily.css`：降低整点网格对比度，半点改为更轻的点线。
- `插件源码/lubi/src/styles/08-v1.4-design.css`：记录时间块采用主题 surface 底色、细边界和中性侧边标记，避免浅色 chip 让记录几乎消失；标题与时长之间增加间距。
- `插件源码/lubi/test/layout/time-polish-layout.mjs`：使用生产渲染的合成数据，检查浅深主题、实际 390px 和 1400px 面板宽度、圆角、时间块层次与条目内容边界。

直接修改原有样式规则，保留工作区已有未提交修改。生成样式已同步至 `.obsidian/plugins/lubi/styles.css`；同步前在仓库外保存旧样式备份。没有手改生成文件、个人日记或任务数据。
